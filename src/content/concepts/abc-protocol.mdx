جاوا «اینترفیس» جدا دارد؛ پایتون دو ابزار معادلِ تمیزتر دارد:

```python
from abc import ABC, abstractmethod
from typing import Protocol

class Shape(ABC):  # اجبار وراثتی
    @abstractmethod
    def area(self): ...

class Drawable(Protocol):  # قرارداد ساختاری، بدون وراثت
    def draw(self) -> None: ...

def render(item: Drawable) -> None:
    item.draw()  # هر شیئی با متد draw قبول است
```

قاعدهٔ انتخاب: چارچوبی که دیگران از آن ارث می‌برند و رفتارِ مشترکِ واقعی هم داری → `ABC`. قراردادی که فقط «شکل» می‌خواهد و نمی‌خواهی سلسله‌مراتب تحمیل کنی → `Protocol`. هر دو از «اینترفیسِ جاواییِ ترجمه‌شده» پایتونیک‌ترند.
