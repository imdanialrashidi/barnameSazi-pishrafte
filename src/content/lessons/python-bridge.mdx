این دوره فرض می‌کند که با پایتون پایه آشنا هستی: متغیر، حلقه، شرط، تابع و کمی کار با لیست و دیکشنری. این درس یک پل است، نه یک دورهٔ مقدماتی کامل. سه ایده‌ای را که در تمام دوره به آن‌ها برمی‌گردیم، همین‌جا محکم می‌کنیم.

## ۱. مسئله را بشکن، بعد بنویس

تفکر از بالا به پایین (Top-down) یعنی اول مسئله را به قدم‌های بزرگ توصیف کنی، بعد هر قدم را به یک تابع تبدیل کنی. یک تابع خوب فقط یک کار انجام می‌دهد و نامش همان کار را می‌گوید.

```python
def read_scores(path):
    """نمره‌ها را از فایل می‌خواند و برمی‌گرداند."""
    with open(path, encoding="utf-8") as f:
        return [float(line.strip()) for line in f if line.strip()]

def average(scores):
    return sum(scores) / len(scores)

def report(path):
    scores = read_scores(path)
    print(f"میانگین {len(scores)} نمره: {average(scores):.1f}")
```

<Callout type="tip" title="قاعدهٔ سرانگشتی">
  اگر برای توضیح کاری که یک تابع می‌کند مجبور شدی از «و» استفاده کنی («می‌خواند و میانگین می‌گیرد و چاپ می‌کند»)، احتمالاً آن تابع دو مسئولیت دارد و باید بشکند.
</Callout>

## ۲. جهش‌پذیر در برابر جهش‌ناپذیر

در پایتون بعضی شیءها بعد از ساخته‌شدن عوض می‌شوند (جهش‌پذیر مثل `list` و `dict`) و بعضی نه (جهش‌ناپذیر مثل `int`، `str` و `tuple`). این تفاوت، منشأ نیمی از باگ‌های عجیب تازه‌کارهاست.

```python
a = [1, 2, 3]
b = a            # b همان شیء a است، نه یک کپی
b.append(4)
print(a)         # [1, 2, 3, 4] — a هم عوض شد!

x = (1, 2, 3)
y = x            # تاپل جهش‌ناپذیر است؛ «تغییر» یعنی شیء تازه
```

<Definition term="ارجاع" id="reference-def">
  متغیر در پایتون جعبه‌ای که مقدار را نگه می‌دارد نیست؛ برچسبی است که به یک شیء در حافظه اشاره می‌کند. انتساب، ارجاع تازه می‌سازد نه کپی.
</Definition>

<Misconception
  wrong="با b = a یک کپی مستقل از لیست ساخته می‌شود."
  correct="با b = a هر دو نام به یک شیء اشاره می‌کنند. برای کپی واقعی از list(a)، a.copy()‎ یا copy.deepcopy برای ساختارهای تودرتو استفاده کن."
/>

## ۳. پروژهٔ کوچک، ساختار تمیز

حتی یک تمرین سه‌فایلی باید ساختار داشته باشد: هر فایل یک مسئولیت، و نقطهٔ ورود مشخص با نگهبان `__main__`.

```python
# shop/cart.py
def total(items):
    """جمع قیمت اقلام سبد را برمی‌گرداند."""
    return sum(item["price"] * item["qty"] for item in items)
```

```python
# shop/main.py
from cart import total

def main():
    items = [{"price": 12000, "qty": 2}, {"price": 8000, "qty": 1}]
    print(total(items))

if __name__ == "__main__":
    main()
```

<Callout type="warning" title="چرا نگهبان __main__؟">
  بدون این نگهبان، هر بار که فایل را `import` کنی کد سطح ماژول اجرا می‌شود. نگهبان یعنی: «این بخش فقط وقتی اجرا شود که فایل مستقیم اجرا شده، نه وقتی وارد شده است».
</Callout>

## از کجا بفهمی آماده‌ای؟

<Prerequisite ids={["functions-responsibility", "mutability-identity", "modules-structure"]} />

اگر بتوانی بدون اجرای کد بگویی خروجی تکهٔ زیر چیست، آمادهٔ ورود به دنیای شیءگرا هستی:

```python
def add_tag(tags, tag="new"):
    tags.append(tag)
    return tags

a = []
print(add_tag(a))
print(add_tag(a))
```
