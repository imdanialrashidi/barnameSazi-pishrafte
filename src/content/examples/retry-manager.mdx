```python
from contextlib import contextmanager

attempts = {"n": 0}

@contextmanager
def connection():
    print("اتصال باز شد.")
    try:
        yield "conn"
    finally:
        print("اتصال بسته شد.")

def fragile_fetch():
    attempts["n"] += 1
    if attempts["n"] < 3:
        raise ConnectionError("قطعی موقت.")
    return "داده رسید!"

with connection():
    for i in range(3):
        try:
            print(fragile_fetch())
            break
        except ConnectionError as e:
            print(f"تلاش {i+1} ناموفق: {e}")
```

<Callout type="warning" title="فقط خطای موقت">
  تلاش مجدد فقط برای خطایِ گذراست (قطعی شبکه). خطای قطعی (احراز هویت، ورودی نامعتبر) را دوباره امتحان نکن — هم کندی، هم خطر (مثل شارژِ دوباره!).
</Callout>
