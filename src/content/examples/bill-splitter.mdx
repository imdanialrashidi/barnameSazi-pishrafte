    { title: 'گام ۳ — پیاده‌سازی', content: 'کد نهایی: هر تابع یک کار. تابع share را می‌شود جداگانه تست کرد.', latex: "share = \\frac{total}{people}" },
    { title: 'گام ۴ — بررسی', content: 'با ۱۲۵۰۰۰ و ۱۰٪ و ۳ نفر: جمع ۱۳۷۵۰۰ و سهم هر نفر ۴۵۸۳۳.۳۳ می‌شود. گردکردن نمایشی با :.2f', latex: "share = \\frac{137500}{3} \\approx 45833.33" },

```python
def with_tip(bill, percent):
    return bill * (1 + percent / 100)

def share(total, people):
    if people <= 0:
        raise ValueError("تعداد نفرات باید مثبت باشد.")
    return total / people

def main():
    total = with_tip(125000, 10)
    print(f"سهم هر نفر: {share(total, 3):.2f}")

if __name__ == "__main__":
    main()
```

<Callout type="tip" title="نکتهٔ طراحی">
  `share` ورودی را اعتبارسنجی می‌کند و خالص است؛ `main` فقط ارکستراسیون. همین جدایی را در کل دوره (مخصوصاً GUI) دوباره می‌بینی.
</Callout>
