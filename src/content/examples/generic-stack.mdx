```python
from typing import TypeVar, Generic

T = TypeVar("T")

class Stack(Generic[T]):
    def __init__(self) -> None:
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        if not self._items:
            raise IndexError("پشته خالی است.")
        return self._items.pop()

    def peek(self) -> T:
        if not self._items:
            raise IndexError("پشته خالی است.")
        return self._items[-1]

s: Stack[str] = Stack()
s.push("اول")
s.push("دوم")
print(s.pop())  # دوم
```

<Callout type="tip" title="کِی جنریک؟">
  وقتی منطق برای همهٔ نوع‌ها یکی است (نگهدارنده‌ها، کش‌ها، صف‌ها). وقتی رفتار واقعاً بین نوع‌ها فرق می‌کند، جنریکِ دروغین نزن — singledispatch یا تابع جدا.
</Callout>
